# Everora AI — Every Celebration, Beautifully Planned.

An AI-powered event planning platform that helps users plan, organize, and manage memorable celebrations with intelligent recommendations and interactive tools.

## ✨ Features

- AI-powered event plan generation using Google Gemini
- Dynamic budget planning and cost optimization
- Guest management and seating arrangements
- Vendor management and tracking
- Event timelines and day-of run sheets
- Inspiration gallery and moodboard generation
- AI event planning assistant
- Event plan export and printable reports

## 🛠️ Tech Stack

- Frontend: React, TypeScript
- Backend: Node.js, Express
- AI Integration: Google Gemini API
- Styling: CSS
- Build Tool: Vite

## 🔐 Environment Setup

Add your Gemini API key to your server-side environment configuration.

Never commit API keys or `.env` files to GitHub.

## 🚀 Project Goal

To simplify event planning through AI-powered intelligence, smart budgeting, and seamless event management.
